Central de ajuda

Como você quer usar o Codex?

Escolha uma ferramenta para abrir o guia completo de instalação, configuração e acesso.

Acesso temporário disponível

Codex CLI

Use o ambiente compartilhado diretamente no terminal, sem entrar na conta central.

1

Instale o Codex CLI

Instale primeiro o Node.js LTS. Depois abra o PowerShell ou CMD e instale o CLI:

npm install -g @openai/codex

No Terminal do macOS, use o instalador oficial ou npm:

curl -fsSL https://chatgpt.com/codex/install.sh | sh

No Terminal do Linux, instale via npm ou script oficial:

npm install -g @openai/codex

Confira a instalação com codex --version.

2

Configure o provedor de modelo (apenas 1 vez)

Configure em 1 clique com o comando automático ou edite o arquivo manualmente:

Ou cole no arquivo %USERPROFILE%\.codex\config.toml:

model = "gpt-5.6-sol"
model_provider = "fecart"

[model_providers.fecart]
name = "FECART Codex"
base_url = "https://.../api/codex/v1"
env_key = "FECART_CODEX_TOKEN"
wire_api = "responses"
supports_websockets = false

Ou cole no arquivo ~/.codex/config.toml:

model = "gpt-5.6-sol"
model_provider = "fecart"

[model_providers.fecart]
name = "FECART Codex"
base_url = "https://.../api/codex/v1"
env_key = "FECART_CODEX_TOKEN"
wire_api = "responses"
supports_websockets = false

Ou cole no arquivo ~/.codex/config.toml:

model = "gpt-5.6-sol"
model_provider = "fecart"

[model_providers.fecart]
name = "FECART Codex"
base_url = "https://.../api/codex/v1"
env_key = "FECART_CODEX_TOKEN"
wire_api = "responses"
supports_websockets = false

Essa configuração é feita apenas uma vez. Para voltar ao Codex padrão da OpenAI a qualquer momento, clique em Restaurar / Desativar.

3

Abra a pasta do seu projeto

No Explorador de Arquivos, copie o caminho da pasta. No terminal, entre nela antes de iniciar:

cd "C:\caminho\do\seu-projeto"

No Finder, localize a pasta do projeto. No Terminal, entre nela antes de iniciar:

cd "/Users/seu-usuario/projetos/seu-projeto"

No Terminal, entre na pasta do seu projeto:

cd "~/projetos/seu-projeto"

O Codex executa localmente exatamente na pasta atual do seu terminal.

4

Agende e encontre seu acesso

  1. Na aba Geral, faça o agendamento e aguarde a aprovação.
  2. Quando a sessão começar, volte ao card Acesso temporário.
  3. Deixe Codex CLI selecionado e escolha seu terminal.
  4. Clique em Copiar ao lado do comando.
5

Execute o comando copiado

Cole o comando no terminal já aberto na pasta do projeto. O exemplo abaixo é propositalmente mascarado:

$env:FECART_CODEX_TOKEN = "••••••••"; codex
export FECART_CODEX_TOKEN='••••••••' && codex
export FECART_CODEX_TOKEN='••••••••' && codex

Não envie o token por mensagem nem salve em arquivos públicos. O CLI executa localmente e consome inferência por conexão segura HTTPS.

6

Se algo não funcionar

“codex” não foi encontradoFeche e abra novamente o terminal. Se continuar, reinstale o CLI e confira o PATH.

Acesso recusadoConfirme se a sessão está ativa, se não foi revogada e copie novamente o comando na aba Geral.

Token ou cota esgotadaConfirme se a cota aprovada para a sessão não atingiu 100%. Se necessário, solicite um novo agendamento.

Sessão terminouO token expira automaticamente. Faça um novo agendamento para obter outro acesso.

Codex App

Use o aplicativo no Windows ou macOS conectado ao ambiente remoto da sessão.

O App usa uma chave SSH temporária, não o token do CLI

A chave aparece em Geral > Acesso temporário somente durante a sessão ativa. Revogar, desabilitar ou deixar a sessão expirar também encerra o acesso SSH.

1

Instale e abra o aplicativo

Acesse a página oficial, escolha Windows e conclua a instalação. Confirme também que o recurso Cliente OpenSSH está instalado no Windows.

Acesse a página oficial, escolha macOS e mova o aplicativo para a pasta Aplicativos quando solicitado. O cliente SSH já acompanha o macOS.

Entre no aplicativo com sua conta pessoal do ChatGPT; a conta compartilhada da sessão permanece autenticada somente no host.

Abrir download oficial
2

Ative sua sessão no site

  1. Faça um agendamento e aguarde a aprovação.
  2. Durante o horário aprovado, abra Geral > Acesso temporário.
  3. Selecione Codex App e baixe a chave privada.

A chave é exclusiva da sessão. O guia nunca mostra uma chave ou token real.

3

Instale a chave na pasta SSH

Mova o arquivo baixado para %USERPROFILE%\.ssh e mantenha o nome exibido no download.

New-Item -ItemType Directory -Force "$HOME\.ssh"
Move-Item "$HOME\Downloads\fecart-••••••••_ed25519" "$HOME\.ssh\fecart-••••••••_ed25519"
icacls "$HOME\.ssh\fecart-••••••••_ed25519" /inheritance:r /grant:r "$($env:USERNAME):(R)"

No Terminal, mova a chave e restrinja as permissões:

mkdir -p ~/.ssh
mv ~/Downloads/fecart-••••••••_ed25519 ~/.ssh/
chmod 600 ~/.ssh/fecart-••••••••_ed25519
4

Adicione o host ao SSH

No card do Codex App, clique em Copiar configuração SSH e cole o conteúdo no arquivo ~/.ssh/config. O exemplo é propositalmente mascarado:

Host fecart-••••••••
  HostName servidor.exemplo
  User fecart-host
  IdentityFile ~/.ssh/fecart-••••••••_ed25519

Confira sem conectar usando ssh -G fecart-••••••••.

5

Abra o workspace remoto no App

  1. No Codex App, abra Settings > Connections > SSH.
  2. Adicione o host cujo nome aparece no card de acesso.
  3. Escolha a pasta remota mostrada em Pasta remota.
  4. Inicie a conversa. Arquivos e comandos dessa conversa rodam no ambiente remoto.

Salve ou envie seu trabalho antes do fim da sessão. A conexão é encerrada automaticamente quando o acesso termina.
