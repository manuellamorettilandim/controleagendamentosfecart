Configuração Unificada

Guia de Configuração: Codex CLI & Desktop App

Aprenda a instalar, ativar o provedor compartilhado do FECART ou desinstalar para voltar à sua conta pessoal.

Compatibilidade Total entre CLI e App Desktop

O Codex CLI (terminal) e o Codex App (aplicativo desktop) utilizam o mesmo arquivo de configuração (config.toml). Ao ativar a configuração abaixo, ambos passam a usar o provedor compartilhado. Para voltar a usar qualquer conta pessoal ou o padrão oficial da OpenAI a qualquer momento, basta utilizar os comandos de Desinstalar / Restaurar.

1

Instalação do Codex

Instale o CLI no seu terminal ou baixe o aplicativo desktop oficial da OpenAI:

Codex CLI (Terminal)

Requer Node.js LTS. No PowerShell ou CMD:

npm install -g @openai/codex

No Terminal do macOS:

npm install -g @openai/codex

No Terminal do Linux:

npm install -g @openai/codex

Método Manual: Passo a Passo

Se preferir editar o arquivo de configuração manualmente no seu editor de texto:

1. Localização do arquivo:

Abra o Explorador de Arquivos e acesse: %USERPROFILE%\.codex\config.toml (ex: C:\Users\SeuNome\.codex\config.toml)

No Finder ou Terminal: ~/.codex/config.toml (ou /Users/seu-usuario/.codex/config.toml)

No Terminal: ~/.codex/config.toml (ou /home/seu-usuario/.codex/config.toml)

Dica de Segurança: Antes de modificar, faça uma cópia do seu arquivo original renomeando-o para config.toml.bak na mesma pasta.

Como Executar seu Acesso na Sessão Aprovada

No Codex CLI (Terminal):
  1. Abra a pasta do seu projeto no terminal (cd "C:\meu-projeto").
  2. Na tela de Visão Geral, copie o comando da sessão aprovada: 
    $env:FECART_CODEX_TOKEN = "••••••••"; codex
    export FECART_CODEX_TOKEN='••••••••' && codex
    export FECART_CODEX_TOKEN='••••••••' && codex
  3. Cole e execute. O CLI conectará instantaneamente ao proxy!
No Codex App (Desktop):

Como o App lê o mesmo config.toml, defina o token da sessão para o App:

Opção A (Variável de Usuário no Windows):

setx FECART_CODEX_TOKEN "••••••••"

(Abra o Codex App pelo Menu Iniciar após definir)

Opção B (Iniciar pelo PowerShell com a variável):

$env:FECART_CODEX_TOKEN = "••••••••"; Start-Process "codex"

Opção A (Via Terminal):

FECART_CODEX_TOKEN="••••••••" open -a "Codex"

Opção B (Variável Global):

launchctl setenv FECART_CODEX_TOKEN "••••••••"

Opção A (Via Terminal):

FECART_CODEX_TOKEN="••••••••" codex-desktop
Suporte por SSH

Codex App

Use o aplicativo no Windows ou macOS conectado ao ambiente remoto da sessão.

O App usa uma chave SSH temporária, não o token do CLI

A chave aparece em Geral > Acesso temporário somente durante a sessão ativa. Revogar, desabilitar ou deixar a sessão expirar também encerra o acesso SSH.

1

Instale e abra o aplicativo

Acesse a página oficial, escolha Windows e conclua a instalação. Confirme também que o recurso Cliente OpenSSH está instalado no Windows.

Acesse a página oficial, escolha macOS e mova o aplicativo para a pasta Aplicativos quando solicitado. O cliente SSH já acompanha o macOS.

Entre no aplicativo com sua conta pessoal do ChatGPT; a conta compartilhada da sessão permanece autenticada somente no host.

Abrir download oficial
2

Ative sua sessão no site

  1. Faça um agendamento e aguarde a aprovação.
  2. Durante o horário aprovado, abra Geral > Acesso temporário.
  3. Selecione Codex App e baixe a chave privada.

A chave é exclusiva da sessão. O guia nunca mostra uma chave ou token real.

3

Instale a chave na pasta SSH

Mova o arquivo baixado para %USERPROFILE%\.ssh e mantenha o nome exibido no download.

New-Item -ItemType Directory -Force "$HOME\.ssh"
Move-Item "$HOME\Downloads\fecart-••••••••_ed25519" "$HOME\.ssh\fecart-••••••••_ed25519"
icacls "$HOME\.ssh\fecart-••••••••_ed25519" /inheritance:r /grant:r "$($env:USERNAME):(R)"

No Terminal, mova a chave e restrinja as permissões:

mkdir -p ~/.ssh
mv ~/Downloads/fecart-••••••••_ed25519 ~/.ssh/
chmod 600 ~/.ssh/fecart-••••••••_ed25519
4

Adicione o host ao SSH

No card do Codex App, clique em Copiar configuração SSH e cole o conteúdo no arquivo ~/.ssh/config. O exemplo é propositalmente mascarado:

Host fecart-••••••••
  HostName servidor.exemplo
  User fecart-host
  IdentityFile ~/.ssh/fecart-••••••••_ed25519

Confira sem conectar usando ssh -G fecart-••••••••.

5

Abra o workspace remoto no App

  1. No Codex App, abra Settings > Connections > SSH.
  2. Adicione o host cujo nome aparece no card de acesso.
  3. Escolha a pasta remota mostrada em Pasta remota.
  4. Inicie a conversa. Arquivos e comandos dessa conversa rodam no ambiente remoto.

Salve ou envie seu trabalho antes do fim da sessão. A conexão é encerrada automaticamente quando o acesso termina.
