Guia de Configuração: Codex CLI & ChatGPT Desktop

Aprenda a instalar, ativar o provedor compartilhado do FECART ou desinstalar para voltar à sua conta pessoal.

Precisa de ajuda ou tem dúvidas?

Em caso de qualquer dúvida, problema com agendamento ou configuração, contate o Comitê de Gestão de Projetos (qualquer integrante) ou o representante da sua sala.

Compatibilidade Total entre CLI e App Desktop

O Codex CLI (terminal) e o ChatGPT Desktop (aplicativo) utilizam o mesmo arquivo de configuração (config.toml). Ao ativar a configuração abaixo, ambos passam a usar o provedor compartilhado. Para voltar a usar qualquer conta pessoal ou o padrão oficial da OpenAI a qualquer momento, basta utilizar os comandos de Desinstalar / Restaurar.

1

Instalação do Codex & ChatGPT

Instale o CLI no seu terminal ou baixe o aplicativo desktop oficial da OpenAI:

Codex CLI (Terminal)

Requer Node.js LTS. No PowerShell ou Prompt de Comando (CMD):

npm install -g @openai/codex

No Terminal do macOS (Zsh ou Bash):

npm install -g @openai/codex

No Terminal do Linux (Bash ou Zsh):

npm install -g @openai/codex

Escolha o seu método de configuração preferido

Ambos os métodos abaixo realizam a mesma configuração no seu arquivo config.toml e chegam exatamente ao mesmo resultado. Escolha a opção que você preferir:

Opção 1 (Recomendada) Método Fácil (1 Clique no Terminal)

Ideal para agilidade. Executa o comando que cria backup e configura tudo automaticamente em 1 segundo.

Opção 2 (Manual) Método Manual Passo a Passo

Para quem prefere não rodar comandos automáticos e quer abrir, verificar e editar o arquivo manualmente no editor.

⚠️ Atenção ao Backup do seu config.toml

Antes de aplicar qualquer alteração, o comando cria uma cópia de segurança renomeando para config.toml.bak. Anote ou confira o caminho do backup informado no seu terminal para que você possa reverter facilmente e voltar à sua conta pessoal quando terminar sua sessão.

Como Executar seu Acesso na Sessão Aprovada

Com o config.toml configurado (pela Opção 1 ou Opção 2), utilize o comando da sua sessão quando ela estiver ativa:

No Codex CLI (Terminal):
  1. Abra a pasta do seu projeto no terminal (cd "C:\meu-projeto").
  2. Na tela de Visão Geral, copie o comando da sessão aprovada:

    No Windows PowerShell:

    $env:FECART_CODEX_TOKEN = "••••••••"; codex

    No Windows CMD:

    set "FECART_CODEX_TOKEN=••••••••" && codex

    No Terminal do macOS:

    export FECART_CODEX_TOKEN='••••••••' && codex

    No Terminal do Linux:

    export FECART_CODEX_TOKEN='••••••••' && codex
  3. Cole e execute. O CLI conectará instantaneamente ao proxy da FECART!
No ChatGPT Desktop (Modo Codex):
Atenção: Feche o aplicativo antes de executar o comando

Se o ChatGPT Desktop já estiver aberto no seu computador, feche-o completamente (inclusive na bandeja ao lado do relógio) antes de rodar o comando, para que a nova variável de ambiente FECART_CODEX_TOKEN seja carregada na inicialização.

Como o app lê o mesmo config.toml, abra o aplicativo carregando a variável de ambiente:

Opção A (Variável de Usuário no Windows — Recomendado):

setx FECART_CODEX_TOKEN "••••••••"

(Após executar o comando acima no terminal, basta abrir o ChatGPT normalmente pelo Menu Iniciar ou Barra de Tarefas)

Opção B (Iniciar direto pelo PowerShell / Microsoft Store):

setx FECART_CODEX_TOKEN "••••••••"; Start-Process "explorer.exe" "shell:AppsFolder\OpenAI.Codex_2p2nqsd0c76g0!App"

Opção A (Via Terminal):

FECART_CODEX_TOKEN="••••••••" open -a "ChatGPT"

Opção B (Variável Global):

launchctl setenv FECART_CODEX_TOKEN "••••••••"

Opção A (Via Terminal):

FECART_CODEX_TOKEN="••••••••" chatgpt
