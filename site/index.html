Fluxo

O relay só encaminha frames.

O cliente abre WSS /codex; o host abre WSS /tunnel. Cada stream é ligado a um WebSocket local do app-server. As mensagens do app-server não são traduzidas nem armazenadas.

Codex CLI ── token ──▶ Relay ── túnel ──▶ Host

                                         └── localhost → app-server → OpenAI
