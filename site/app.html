Codex App desktop

Limite conhecido: não existe, neste projeto, uma configuração oficial documentada para trocar o endpoint do Codex App desktop por um relay customizado.

O app-server é uma interface pensada para clientes ricos, mas a conexão customizada do aplicativo desktop continua experimental. Por isso esta página não promete compatibilidade automática.

Como testar sem comprometer o host

  1. Valide primeiro o CLI remoto usando uma máquina de teste.
  2. Confirme que o relay está em wss://, com token de dispositivo separado.
  3. Use o Codex App somente se a versão instalada oferecer uma opção explícita de servidor remoto/endpoint WebSocket.
  4. Se a opção não existir, não tente substituir arquivos internos do aplicativo: mantenha o teste como experimento manual.

Resultado esperado

O app experimental deve apontar para wss://SEU_RELAY.onrender.com/codex e enviar o token do dispositivo no cabeçalho suportado pela versão testada. Se a versão não permitir isso, o CLI continua sendo o cliente documentado da v1.
