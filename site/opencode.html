OpenCode não é compatível na v1

Não conecte o OpenCode diretamente a /codex esperando que ele funcione como um provider OpenAI.

O OpenCode documenta providers OpenAI-compatible com baseURL e endpoints HTTP de modelo. O Codex app-server usa JSON-RPC sobre WebSocket para uma interface de cliente diferente. O relay desta v1 encaminha frames do app-server sem convertê-los.

Fase 2: seria necessário um adaptador separado, com uma decisão explícita sobre API key, modelos, streaming, histórico e permissões. Essa ponte não faz parte desta implementação.

O que não fazer

  • Não apontar baseURL do OpenCode para /codex.
  • Não colocar o token do dispositivo em uma URL.
  • Não copiar auth.json ou API keys para configurar um provider remoto.

Veja a documentação de Providers do OpenCode e compare com a documentação do OpenAI App Server.
