Conectar um PC remoto

O CLI remoto usa o app-server da máquina central através do relay. Não execute codex login no PC remoto.

1. No host central

codex login
$env:RELAY_URL = "wss://SEU_RELAY.onrender.com"
$env:RELAY_AGENT_TOKEN = "SEGREDO_DO_TUNEL"
npm.cmd run host

O host agent inicia o app-server local em 127.0.0.1:4500, abre o túnel de saída e sincroniza os hashes dos dispositivos. O segredo do túnel fica somente no host.

2. Emitir o token do dispositivo

npm.cmd run access -- issue --label pc-notebook --ttl 30d

Copie o token exibido uma vez. O arquivo local de acesso guarda apenas o hash; não há comando para recuperar o token depois.

3. No PC remoto

$env:CODEX_REMOTE_TOKEN = "TOKEN_DO_DISPOSITIVO"
codex --remote wss://SEU_RELAY.onrender.com --remote-auth-token-env CODEX_REMOTE_TOKEN
Importante: o token acima autoriza o relay, não autentica na OpenAI. Ainda assim, trate-o como segredo e não o coloque em scripts públicos, URL ou logs.

Diagnóstico

  • /healthz deve responder 200 quando o relay está vivo.
  • /readyz responde 200 somente depois do host registrar e sincronizar.
  • Se o host parar, o relay encerra a sessão e novas conexões retornam 503.
