Emitir e cortar dispositivos

O registro fica na máquina central, por padrão em $CODEX_HOME/remote-access.json. Ele contém deviceId, label, hash do token, datas de criação/expiração, revogação e último acesso.

Emitir

npm.cmd run access -- issue --label pc-notebook --ttl 30d

O token bruto aparece somente nesta saída. Salve-o no gerenciador de segredos ou diretamente como variável de ambiente no PC remoto.

Listar

npm.cmd run access -- list

O status pode ser active, expired ou revoked. A sincronização do host remove acessos expirados do conjunto aceito pelo relay.

Revogar

npm.cmd run access -- revoke device-XXXXXXXX
npm.cmd run access -- revoke-all

O host agent detecta a alteração, envia a nova sincronização e o relay fecha a sessão do dispositivo afetado. Com revoke-all, todos os clientes são cortados.

Painel administrativo: use /admin com Supabase Auth para emitir, desabilitar, reabilitar e revogar dispositivos sem expor o login OpenAI.
