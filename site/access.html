Emitir e cortar dispositivos

Prefira o painel administrativo. Ele permite escolher a conta, definir o percentual máximo da janela semanal, escolher a expiração e copiar o token ou o comando remoto com um clique.

Política

Cada conta pode ter um token não revogado. Desabilitar é temporário. Revogar é permanente: o registro fica no histórico, mas o token não pode ser reabilitado. Emita outro token se ele for perdido ou substituído.

Uso observado

O host captura os eventos thread/tokenUsage/updated do app-server e mostra tokens de entrada, cache, saída e raciocínio por dispositivo. O percentual semanal oficial é da conta inteira, não do token; portanto o painel separa o uso observado do token do limite global da conta. Consulte a referência oficial do app-server.

Fallback local

Se o painel estiver indisponível, os comandos locais continuam existindo:

npm.cmd run access -- list
npm.cmd run access -- disable device-XXXXXXXX
npm.cmd run access -- enable device-XXXXXXXX
npm.cmd run access -- revoke device-XXXXXXXX
npm.cmd run access -- revoke-all
Segurança: o token bruto não é salvo no Supabase, Render, registro local ou logs. Depois de fechar o modal de emissão, ele só pode ser substituído por uma nova emissão.
